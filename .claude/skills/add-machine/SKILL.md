# 機種追加の手順

引数で機種名を受け取る（例: `/add-machine モンハンライズ`）。不明なら確認する。

1. **仕様を確認する**
   ユーザーに次を確認する（推測で数値を作らない）:
   - 数えたい項目（小役、CZ、周期など）
   - 設定推測に使う確率や当選率と、その出典
   - リロード後も残したい値（localStorage に保存するもの）

2. **ロジックを先に作る**
   - 確率計算などは `src/machines/<機種>/` に純粋関数か hook として置く
   - 既存の `useCount(storageKey)` を再利用する。storageKey には `<機種>-` を前置して、他機種と重複させない
   - 先にテスト（`*.test.tsx`）を書き、境界値（0回、極端な値）も含める

3. **UI を作る**
   - 共通部品の `CountUp` と `Stepper` を使う。部品が足りないときだけ `src/components/` に追加する
   - 機種の画面コンポーネントは `src/machines/<機種>/<機種>Page.tsx`

4. **画面に組み込む**
   - 機種が2つ以上になったら、`App.tsx` に機種の切り替え（タブなど）を入れる。選択中の機種は localStorage に保存する
   - 初めて切り替えを入れるときは、既存のカバネリ画面も `src/machines/kabaneri/` へ移す。移動は別コミットにする

5. **検証する**
   - `npm run check` を通す
   - 可能なら `npm run dev` で表示を確認する
